Analyze anything.
Install nothing.

Reverso is a native-first reverse engineering toolkit. Triage unknown binaries, inventories of JavaScript bundles and offline website mirrors, from one CLI or one MCP server. Everything runs locally, with zero runtime dependencies and no Ghidra, Hopper, IDA or license server.

What it does

  • Full triage reports

    reverso analyze: hashes, entropy, format, strings, layout, hardening, archives and JavaScript in one JSON or Markdown report.

  • Native binary parsers

    ELF, PE and Mach-O: sections, program headers, imports, exports. Hardening checks for PIE, NX, RELRO, FORTIFY, ASLR, CFG and Authenticode.

  • JavaScript analysis

    Minification detection, obfuscation score, framework fingerprints, source maps, URL and API endpoint extraction, secret scanning.

  • DEX, WASM and PCAP

    Android DEX header and categorized string table, WebAssembly sections and names, and classic PCAP protocol statistics with top talkers.

  • Directory triage & diff

    reverso scan triages a whole directory recursively. reverso diff compares two builds structurally: traits, sections, imports, strings.

  • Built for agents

    reverso mcp serves every analyzer as a Model Context Protocol tool over stdio. Point your agent at it, get deterministic answers.

Install

From source, no global package needed beyond Node.js.

git clone https://github.com/nekonaru/reverso.git
cd reverso
npm ci
npm run build
npm link
reverso doctor

Requires Node.js ^22.23.4, ^24.22.1 or >=26.12.1. Analysis is static; nothing you analyze is executed. Use only on targets you are authorized to analyze.

Use it from your agent

reverso mcp speaks Model Context Protocol over stdio (protocol 2025-06-18). Add it to your client:

{
  "mcpServers": {
    "reverso": {
      "command": "reverso",
      "args": ["mcp"]
    }
  }
}

    FAQ

    Does Reverso execute the binary it analyzes?

    No. All analysis is static. Nothing is loaded, run or emulated.

    Does it need an internet connection?

    No for analysis. Only the test suite binds to loopback during development, and reverso site fetches the site you explicitly ask it to mirror.

    Can it decompile to pseudocode?

    No. Reverso triages, inventories and scores. Feed the file to a dedicated decompiler for interactive work; use Reverso for triage, extraction and reporting.

    Is the source code open?

    Yes, under MIT. github.com/nekonaru/reverso
