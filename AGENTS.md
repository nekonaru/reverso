Reverso is a native-first reverse engineering toolkit: a CLI and an MCP server
that analyze binaries, JavaScript bundles and web applications locally, with no
proprietary dependencies. It is an independent reimplementation informed by a
study of publicly available analysis tooling. No source code from other
projects is included.
